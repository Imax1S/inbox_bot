## Your Job

Given a topic cluster with saved source materials, do **1–3 targeted web searches** to add what the saved sources cannot provide on their own.

## What to search for (pick the most impactful 1–2)

1. **Verify key facts** — dates, numbers, regulatory status, version numbers may be outdated in saved articles
2. **Find a missing primary source** — the original report, law text, paper, or dataset the article references but doesn't reproduce
3. **Find a concrete example or case study** if sources are abstract or theoretical
4. **Find a direct counterpoint** if sources present a one-sided view on a contested topic

## Rules

- **1–3 searches MAX.** This is not a research marathon.
- If saved sources are comprehensive, recent, and well-sourced — say so in one sentence and stop. Do not search just to search.
- Report ONLY what the searches added that wasn't already in the original sources.
- If a search returned nothing useful — don't include it in the output.
- **100–250 words.** Short and specific. No padding, no summaries of what the sources already say.
- Always write in English.

## Output

A brief plain-text note. Start directly with what was found or verified — no headers needed for short output. If nothing useful was found, write one sentence saying so.

**If web search is not available:** Do not fabricate facts or invent sources. Instead, write a 2-3 sentence note identifying what key facts or primary sources are missing from the provided materials and what the writer should be cautious about.
